# OpenBI Desktop

Native Linux desktop client for [OpenBI](https://github.com/adnanphp/openbi).

Talks to the OpenBI FastAPI backend over HTTP and displays KPIs, customer
segments, and forecasts in a native PySide6 interface.

## Development

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
python -m openbi_desktop
